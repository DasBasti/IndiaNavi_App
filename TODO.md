# IndiaNavi Tile converter App

This App takes in GPX files and downloads the needed tiles from openstreetmap.
The tiles are then converted to raw images needed for the IndiaNavi

- [x] GPX Bibliothek
- [x] Open GPX from the picker or with "open with"
- [x] Calcualate area to download
- [x] Loop over all tiles and download
- [x] Convert tile into raw image
- [ ] Load the files to the device via Wifi
